# Handwritten Character Recognition Using CNN

## Project Overview
This project recognizes handwritten digits using a Convolutional Neural Network (CNN) trained on the MNIST dataset.

## Objectives
- Recognize handwritten digits from 0 to 9.
- Train a CNN model using image data.
- Evaluate model performance using test accuracy and a classification report.
- Visualize training results and predictions.

## Technologies Used
- Python
- TensorFlow and Keras
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab
- MNIST Dataset

## Methodology
1. Load the MNIST dataset.
2. Normalize image pixel values.
3. Build a CNN with convolution, pooling, and dense layers.
4. Train the model and validate its performance.
5. Evaluate test accuracy and generate a confusion matrix.
6. Display sample predictions.
7. Save the trained model.

## Files
- `CodeAlpha_Handwritten_Character_Recognition.ipynb` - Complete implementation and results.
- `handwritten_digit_cnn.keras` - Saved trained model.
- `handwritten_recognition.py` - Python project notes.
